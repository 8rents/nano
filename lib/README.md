# Nano Modules Library

> *3rd party modules for nano. Items in the `lib` folder are ignored by git.*

---

## Installation

To make use of the included submodules, either:

### When first cloning this repo

Include the `--recursive` flag on the `clone` command.

```bash
git clone --recursive https://github.com/8rents/nano-syntax-highlighting
```

### Or if You've already cloned this repo

Initialize and update with the `submodule` command.

```bash
git submodule update --init --recursive
```

## Modules

The following are included in this package as submodules. 

### [8rents/nano-syntax-highlighting](https://github.com/8rents/nano-syntax-highlighting)
